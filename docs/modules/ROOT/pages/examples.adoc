== Range Support (P3168R2)

=== range_loop.cpp

Demonstrates `for`-range iteration over an optional value.

[source,cpp]
----
#include <beman/optional/optional.hpp>

beman::optional::optional<int> empty_opt{};
for ([[maybe_unused]] const auto& i : empty_opt) {
    // not reached — empty optional produces zero iterations
}

beman::optional::optional<int> opt{26};
for (const auto& i : opt) {
    std::cout << "value: " << i << "\n"; // value: 26
}
----

[source,shell]
----
.build/gcc-14/examples/RelWithDebInfo/range_loop
# "for each loop" over C++26 optional: opt = 26
----

https://godbolt.org/z/Gc6Y9j6zf[Try it on Compiler Explorer]

== Optional References (P2988R12)

=== optional_ref.cpp

Demonstrates `optional<T&>` with monadic operations.

[source,cpp]
----
#include <beman/optional/optional.hpp>

struct Cat { std::string name; };

beman::optional::optional<Cat&> find_cat(std::string name) { return {}; }
beman::optional::optional<Cat&> do_it(Cat& cat) { return {cat}; }

beman::optional::optional<Cat&> api() {
    auto cat = find_cat("Fido");
    return cat.and_then(do_it);
}
----

https://godbolt.org/z/MxjdvTTov[Try it on Compiler Explorer]
